# Cybersecurity Asset Inventory System

## Project Description

The Cybersecurity Asset Inventory System is a Python-based application designed to help a security administrator manage and monitor IT assets.

The system allows users to add, display, search, update, and delete asset information. It also classifies assets based on asset type, risk level, and security status.

## Features

- Add new IT assets
- Display all assets
- Search assets using Asset ID
- Update asset information
- Delete assets
- Validate asset type, risk level, and security status
- Display asset statistics

## Asset Information

Each asset contains the following details:

- Asset ID
- Asset Name
- Asset Type
- IP Address
- Operating System
- Owner/Department
- Risk Level
- Security Status

## Asset Types

- Workstation
- Server
- Router
- Switch
- Application

## Risk Levels

- Low
- Medium
- High
- Critical

## Security Status

- Secure
- Warning
- Vulnerable
